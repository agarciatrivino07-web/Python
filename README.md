# 🧮 Python Calculator

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)

![Status](https://img.shields.io/badge/status-active-brightgreen)

Una calculadora sencilla, elegante y funcional construida íntegramente en **Python**. Ideal para realizar operaciones matemáticas básicas con un manejo de errores robusto.

---

## ✨ Características

- **Operaciones Básicas:** Suma, resta, multiplicación y división.
- **Manejo de Errores:** Control de división por cero y entradas no válidas.
- **Interfaz Limpia:** Ejecución fluida a través de la terminal (o GUI si aplica).
- **Código Legible:** Estructura organizada siguiendo las mejores prácticas de Python.

---
